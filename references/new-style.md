# 按参考片新建风格

作者说「照这个片子的风格做」「我要这种感觉」时走这里。先弄清能做到哪一步，再动手。

## 先分清能不能做

一个风格是一个 JSON 文件，定四样：颜色、字幕和字体、动作性格、真人放法和混音。**这四样能照着参考片调出来。**

下面这些不归风格文件管，现有的拼不出来就要改引擎代码，先告诉作者，不要硬凑：

- 新的版式。现在只有 `S` 画板、`A` 全屏真人、`F` 无真人、`W` 全屏素材。
- 新的动作。先在[动作词汇](vocabulary.md)里找最接近的；没有的才新写。
- 新的真人放法。现在只有 `card` 卡片、`half` 半屏、`bubble` 圆形小窗。
- 新的字体。内置思源黑体 700 / 900 和一款毛笔字；别的字体要把字体文件放进 `assets/fonts/` 并在 `engine/motion.css` 里登记。

只学版式、配色、节奏这些手法。别人的名字、头像、标志和原素材不做进去，风格文件也不用别人的名字命名。

## 流程

### 1. 看参考片

```bash
node $RS/bin/rs.mjs ref <参考视频>
```

它抽帧拼成一张对照图，量出主要颜色、平均几秒一个镜头和画幅。用 Read 看对照图和色卡，回答这几个问题：

- 底色是什么，有没有纹理（方格、点阵、暗角）。
- 强调色是哪一个，只用在哪里。面积小但鲜艳的那个通常就是。
- 卡片什么样：圆角大小、有没有投影、和底色差多少。
- 字幕：位置、字号大小、有没有底、是整句还是一次一个词。
- 动作性格：弹不弹、落地有没有震、画面是稳的还是在晃。对照图看不出动作，要播一小段原片，或者直接问作者。
- 真人怎么放，最接近三种里的哪一种。

读数只是线索。真人画面多的片子，肤色和背景会混进色卡，以看图为准。作者只给了截图时，跳过命令直接看图。

### 2. 从最接近的现成风格复制一份

```bash
node $RS/bin/rs.mjs styles
mkdir -p ~/.config/ray-studio/styles
cp $RS/styles/<最接近的>.json ~/.config/ray-studio/styles/<新名字>.json
```

自己建的风格放 `~/.config/ray-studio/styles/`，升级仓库不会冲掉；和自带风格同名时用自己的。名字用小写英文或拼音，描述这种风格本身。

### 3. 改字段

`name` 和 `summary` 写清这是什么风格、适合什么内容，`rs styles` 会列出来。

**颜色（`tokens`）**

| 字段 | 管什么 |
|---|---|
| `bg`、`bg-image` | 底色和底纹。`bg-image` 写 CSS 渐变，不要底纹就写 `none` |
| `surface` | 卡片底色 |
| `ink`、`sub`、`faint` | 主文字、次要文字、最淡的文字和占位 |
| `well`、`line` | 凹下去的格子、分隔线 |
| `accent` | 强调色的色块和线 |
| `accent-text` | 强调色的文字。深色底上要比 `accent` 亮，否则看不清 |
| `accent-ink` | 压在强调色块上面的文字 |
| `ok`、`no` | 胜出和落败的颜色，不写就用默认 |
| `shadow`、`radius` | 卡片投影和圆角 |
| `f-heavy`、`w-heavy` | 标题字体和字重 |

**字幕（`tokens` 里 `cap-` 开头的）**

| 字段 | 管什么 |
|---|---|
| `cap-color`、`cap-accent` | 字幕颜色、标了 `*词*` 的颜色 |
| `cap-bg`、`cap-pad`、`cap-radius` | 字幕底、内边距、圆角。不要底写 `transparent` 和 `0` |
| `cap-size-l`、`cap-weight` | 字号和字重 |
| `cap-a-color`、`cap-a-accent`、`cap-a-bg`、`cap-a-pad` | 全屏真人（`A` 版式）上的字幕。压在人脸和衣服上，颜色和底要单独定 |
| `cap-size-s`、`cap-top-s`、`cap-size-a`、`cap-top-a` | 画板和全屏真人上的字号和纵向位置，不写就用默认 |

最外层写 `"captionWords": true` 时字幕一次只出一个词。

**动作性格（`motion`）**

| 字段 | 0 是什么 | 现成风格的范围 |
|---|---|---|
| `bounce` | 干净减速，不过冲 | 0–1 |
| `shock` | 落地不震 | 0–6 |
| `sway`、`rot` | 镜头不晃、不转 | 0–3.2、0–0.18 |
| `float` | 部件不漂 | 1–3.6 |
| `push` | 不缓慢推近 | 0.03–0.04 |
| `punch` | 全屏真人不在重点词上推近（不写是 0.075） | 0.05–0.09 |

稳重的片子把前四项调到 0 附近，活泼的往上调。先照最接近的现成风格取值，再微调。

**其他**：`person` 写 `card`、`half` 或 `bubble`。`mix` 里 `bgm` 是配乐音量、`sfx` 是音效音量、`lufs` 是成片响度。`"chapters": "tag"` 把顶部章节条换成小标签。

### 4. 对着参考片看

拿一个现成工程（没有就用 `examples/starter`）出帧，不用改工程文件：

```bash
node $RS/bin/rs.mjs check  <工程> --style <新名字>
node $RS/bin/rs.mjs frames <工程> [场景] --style <新名字>
```

`check` 报对比度错误就是真看不清，改颜色，不要放过。用 Read 把出的帧和参考片的对照图放在一起看：底色、强调色、字幕、卡片像不像。不像就回第 3 步改。

### 5. 给作者确认

把新风格的一张帧和参考片的对照图一起给作者，说清三件事：哪些学到了，哪些没学到、为什么，没学到的要不要花时间写代码补。作者认可后，这个风格就可以在 `studio.json` 的 `style` 里直接用。
